# 会话分享

在侧栏会话按钮上右键，选择“分享会话…”，生成并复制链接。默认有效期为 7 天，可选 1 天、30 天或直到撤销。同一位置可以查看和撤销已生成的链接。链接生成后只显示一次，服务端不保存可还原的分享密钥。

访客打开链接，无需主人登录凭证，即可查看这一个会话的用户和助手消息、附件和工具调用记录，并发送文字、图片和附件。访客页面支持 Markdown 和数学公式，每 3 秒刷新；用户和助手消息底部显示浏览器本地时区的年月日和时分秒，悬停可查看含时区的完整时间。时间优先使用消息开始时间，缺少时使用完成时间；均未记录的旧消息显示“时间未知”。历史按逐条消息记录分页，不用整轮会话时间代替消息时间；会话忙碌时消息进入原会话队列。访客无法从页面或分享接口查看其他会话、修改模型和会话选项或处理审批。附件、图片及本地文件复用主人页面的资源预览服务，不增加分享专属的项目目录或引用范围限制。工具记录只读展示，不提供执行、审批或跳转到其他会话的操作。

## 权限边界

分享是对原会话的对话授权，不会创建模型工具的独立沙箱。消息使用原会话已有的能力、权限和工作目录，仍可能触发该会话可执行的操作。对话中已经出现的文本（包括之前引用的内容）会随历史一起展示。模型遇到需要主人批准的操作时，访客不能代为批准。

分享凭证是持有者凭证，转发链接即可转授访问权。请使用接收方可访问的 WebUI 地址生成链接。撤销会阻止之后的读取和发送；已提交给 daemon 的任务和对方已经读到的内容不会被撤回。

## 实现与验证

- 主人接口：GET/POST /api/shares、DELETE /api/shares/:id，使用原有登录校验及写操作 Origin 校验。
- 访客接口：GET /api/shared/conversation、POST /api/shared/messages。凭证置于链接 fragment，随后通过 Authorization: Share 请求头传递；请求不携带主人 cookie。
- 服务端保存固定 thread ID 与密钥哈希，使用常量时间比较。访客不能提供目标 thread ID 或配置选项。历史游标按分享授权签名。资源使用 /api/shared/resources，复用原 ResourceStore 的访问规则；分享凭证不会获得其他主人接口的权限。
- 状态位于 access-token 同级的 conversation-shares.json，原子写入、文件权限 0600。消息提交回执持久化，相同 requestId 和文字不会重复入队，超时结果不确定时也不会自动重发。
- 每条消息最多 8,000 字符，每个链接每分钟最多 12 次新消息提交、总计最多 5,000 条。最多同时存在 200 个有效链接。
- tests/conversation-shares.test.ts 覆盖凭证、隔离、过期、撤销、分页、去重、重启恢复以及并发撤销。消息提交使用模拟 daemon 测试，避免触发真实业务操作。

资源请求使用 Authorization 请求头和 credentials: omit。图片、PDF 与下载使用浏览器内存中的 Blob URL，不将凭证放入资源 URL，不复制服务器原文件。撤销后后续资源请求也会被拒绝，已经读取或下载的内容不能收回。审批和模型、权限等配置修改仍仅主人可操作。

## 文件引用标记

主人页面和分享页面均支持文件引用标记，例如 `:codex-file-citation{path="/data/示例/报告.docx" purpose="output"}`。它会显示文件名和用途，点击打开现有文件预览窗口；无法直接预览的格式（如 DOCX）可下载原文件。支持中文、空格、相对路径以及 file:/// 路径，行内代码和代码块中的示例保留为文字。资源仍从原文件读取，沿用当前访问权限。


## 发送图片与附件

分享页输入框旁的回形针按钮支持多选文件，也可以粘贴截图或把文件拖入输入区域。允许只发附件，不必填写文字。上传成功后显示“待发送”，失败可重试，发送前可移除。每条消息最多 10 个附件，单文件 32 MB（与当前 nginx 请求大小上限一致）。

图片以 daemon 的 localImage 输入提交；PDF、Word、表格等文件以带路径的输入文件引用提交，供原会话按已有工具和权限读取。消息仍进入绑定会话的队列，不传入模型、审批或权限配置。

上传接口为 POST /api/shared/uploads/:id，使用原始二进制请求体、编码后的 X-File-Name 请求头及分享凭证。相同上传 ID 的重试不会重复保存文件。消息携带 attachmentIds，服务端核对所属分享与会话后构建输入；发送回执将附件 ID 纳入去重校验。

原始上传文件只保存一份，位于 access-token 所在目录的同级 codex-daemon-web-uploads 目录；元数据位于 shared-uploads.json。已提交的附件保留供历史引用，移除未发送附件时删除文件，遗留超过 24 小时的未发送上传定期清理。上传和发送过程中会检查链接是否仍有效。
